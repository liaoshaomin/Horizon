## [Alibaba Announces Qwen3.8-Max with Open-Weight Release Plans](https://qwen.ai/blog?id=qwen3.8) ⭐️ 8.0/10

Alibaba has officially introduced Qwen3.8-Max, its most capable flagship model to date, setting new state-of-the-art benchmarks in coding and visual web development. In addition, Alibaba announced plans to open-source the model weights for both the Qwen-Max class and Qwen3.8-27B. Releasing open weights for a top-tier flagship model significantly elevates the baseline performance available for local and self-hosted AI deployments. It gives developers and researchers access to high-performance coding and vision-to-code capabilities without sole reliance on proprietary closed APIs. This marks the first time Alibaba is open-sourcing weights for a Qwen-Max-class model alongside medium-sized variants like 27B. Early visual web development benchmark testing shows strong capabilities in accurately translating complex, rich image designs into functional single-page web applications.

hackernews · ai2027 · Aug 3, 02:16 · [Discussion](https://news.ycombinator.com/item?id=49150470)

**Background**: Qwen is a series of large language models developed by Alibaba Cloud that excels in reasoning, coding, and multilingual tasks. Open-weight models allow users to download model parameters and run inference locally on their own hardware, providing greater privacy and customization control compared to hosted cloud APIs.

**Discussion**: Community members expressed enthusiasm for the release, noting that previous Qwen models like Qwen3.6-27B were top performers for local hardware execution. Early testers praised its performance on image-to-HTML tasks, while others highlighted the global competitive implications of releasing frontier-class open weights.
